# Ветки и слияния
## Создание ветки
__Создать ветку можно 3мя способами__
1) Создать ветку не переключаясь на нее - git branch feature
2) Создать ее и переключиться на нее git switch -c feature
3) Старый способ создать и переключиться git checkout -b feature

## Удаление ветки
__Удалить ветку можно 2мя способами__
1) Мягкое удаление через git branch -d feature - Удаляет, если ветка смержена в другую ветку, чтобы данные не потерялись
2) Принудительное удаление через git branch -D feature - Удаляет ветку насильно

## Показать информацию о ветках
__Узнать какие есть ветку локально можно через git branch__
__Чтобы увидеть ветки, которые отличаются по коммитам от текущей, можно указать так git branch ---no-merged__
__Чтобы увидеть ветки идентичные текущей по коммитам используется git branch --merged__

## Переключиться на уже существующую ветку можно 3мя способами:
1) git checkout feature
2) git switch feature
3) "git switch -" - Переключает на предыдущую ветку
