# Базовый Workflow
__Базовый воркфлоу это внесни изменения -> Добавить их в индекс -> Закоммитить -> Снова внести изменения и тд__

## Создание репозитория
__Создать репозиторий можно 2мя способами:__
1) __Инициализировать репозиторий в новом через git init__
2) __Скопировать существующий через git clone__

## Добавление/исключение файлов с индекса
__Добавить файл в индекс после измеений можно через git add. Если указать git add . то доабвятся все файлы, но так же можно указать имена файлов вместо точки.__

__Игнорировать файлы при добавлении их индекс можно через .gitignore. Это такой файлик куда мы вносим названия файлов. Если хочется исключить все файлы с определенным расширением, то пишем такое *.log__

__Посмотреть какие файлы в индексе можно командой git status. Там есть пометки например new file - Это новый файл или modified это измененный файл__
__Посмотреть коммиты можно командой git log. Там указаны хеши коммитов на которые можно переключится, так же указаны HEAD и ветка,а так же на каком коммите последний раз был удаленный репозиторий пометкой origin/master например.__

## Базовые операции
__git status - показывает состояние изменений в репозитории. Команда выводи список состоящий из блоков: Что готово к коммиту (находится в индексе), что не готово к коммиту (не находится в индексе), какие файлы не отслеживаются (новые файлы)__
__С помощью команды можно понять, какие файлы пойдут в коммит, а какие нет__

__git log - показывает список коммитов и их инфу (хеш, автора, дату)__

### git diff
1) __git diff - показывает построчные изменения в текущем репозитории относительно файлов которые в индексе__
2) __git diff --staged - показывает построчные изменения в индексе относительно коммита__
3) __git diff LICENSE.md - показывает построчные изменения в конкретном файле относительно индекса__
4) __git diff --staged LICENSE.md - показывает построчные изменения в конкретном файле в индексе относительно последнего коммита__
5) __git diff HEAD~1 - показывает построчные изменения в файлах репозитория относительно предыдущего коммита__
6) __git diff HEAD HEAD~2 - Сравнить текущий и предыдущий коммит__

### git add
1) __git add . - Добавляет все файлы с текущего места в индекс__
2) __git add -A - Добавляет все файлы с текущего репозитория в индекс__
3) __git add LICENSE.md - Добавляет конкретный файл в индекс__
4) __git add -p LICENSE.md - Интерактивное добавление изменений в индекс (Управляем что именно пойдет в индекс построчно. Управление через кнопки n - next, y - yes и тд)__

### git commit
1) git commit -m "new" - Создаем коммит с файла в индексе с комментом "new"
2) git commit --amend - Создается новый коммит от предыдущего с новыми изменениями. Предыдущий удаляется. Возникает эффект как будто редактировали последний

## Просмотр истории коммитов и навигация
__Для просмотри истории коммитов используют команду git log. Выводится список всех коммитов с хешем,автором, сообщением. Так же у этой команды есть доп параметры:__
1) git log --one line - Вывести в 1 строку компактно
2) git log --author="Vlad" - Вывести коммиты где автор Vlad
3) git log --grep="docs" - Вывести коммиты где в названии сообщения есть слово docs
4) git log -3 - Вывести 3 последних коммита
5) git log -- LICENSE.md - Вывести все коммиты где менялся файл LICENSE.md
6) git log --stat - Вывести статистику по коммитам (или по конкретному если указать его хеш или относительно текущего коммита через HEAD~2)
7) git log --pretty=format:"%an - %s" - Вывести логи в красивом формате. an - author name - имя автора/ s - тема сообщения.

__Для просмотра инфы по конкретному коммиту используется команда git show (Показывает изменения последнего коммита). У нее так же есть опции:__
1) git show <хеш> - Показать изменения указанного коммита
2) git show HEAD~2 - Показать изменения коммита от текущего на 2 назад
3) git show --stat - Показать ток статистику коммита текущего (Либо указать хеш коммита, либо навгиация через HEAD)
