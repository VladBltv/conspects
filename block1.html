ELK

Что такое ELK - это стек технологий для хранения, фильтрации, обработки и поиска логов. В этот стек входят 3 элемента:

Elasticsearch - база для хранения логов с функцией быстрого поиска. Есть аналог OpenSearch.

Logstash - программа которая принимает на вход логи с разных источников (серверные логи, очереди, логи приложения, логи с БД и др), фильтрует их избавляя от мусора и перекидывает в Elastic.

Kibana - Удобный интерфейс для работы с логами (Поиск человекопонятный, интерфейс). Есть аналог сделанный от создателей OpenSearch - Opensearch Dashboards.

Этот стек является бесплатным, но есть лицензия, которая запрещает эту оболочку ELK переделывать чуть и продавать за свою. Opensearch сделан на базе Elasticsearch

Так же есть платный и дорогой аналог, где весь этот сек вместе - Datadog

Prometheus + Grafana

Так же для сбора данных о состоянии сервера (Диск, оперативка, кол-во запросов) или контейнера используется Prometheus.

Для визуализации данных с Prometheus, используется Grafana - строятся красивые графики

Стек ELK и Prometheus+Grafana используются для отслеживания состояния системы и для настройки алертов, что помогает реагировать на проблемы до жалоб юзеров.

Docker, kubernetes, dockerfiles

Чтобы везде программа работала одинаково, ее упаковывают в Docker образ, закидывая туда все что нужно для работы программы (Код, зависимости и тд).

Докер образ сформировывается слоями и после того как образ был создал, он отправляется в registry(хранилище образов). Самое популярное общее хранилище это DockerHub

Чтобы Докер образ был собран, докеру пишут инструкцию, что нужно сделать и определяют последовательность. Такую инструкцию пишут в dockerfiles

Уже на сервере Докер образ разворачиваю в контейнер. Образ - это программа диактивированная, она не работает, а контейнер, это уже работающая программа, то есть идет ее запуск

Kubernetes - это оркестратор докер контейнеров. Он управляет докерконтенейрами, поднимает новые, распределяет нагрузку, перезагружает упавшие
