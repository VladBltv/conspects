Hard Skills Devops

  • Linux

    • Большая часть серверов работает на Linux на разных сборка типо Debian, Ubuntu, Fedora и тд. И надо знать это для того чтобы зайти на сервер и диагностировать проблему.

  • Сети

    • Знать сети необходимо для настройки сервером для взаимодействия с ними + так же для диагностирования проблем.

  • Docker (Docker Compose - одной командой может развернуть несколько контейнеров. Docker Engine - та часть которая и запускает контейнеры. Кубер с ней взаимодействует. На каждом сервере отдельный Docker Engine)
  • Kubernetes

    • Нужно знать для контроля над докер контейнерами + настройка чтобы система была отказаустойчивой и самовосстанавливающейся

  • CI/CD

    • CI - непрерывная интеграция (Continuous Integration) - по сути этап сборки и тестирования нового кода. Задается пайплайном (инструкция, какой этап за каким должен идти). Стандартный процесс -1) Линтер 2) Компиляция (Если язык компилируемый типо c++, Java, Go, Rust) 3) Запуск в память 4) Тесты (Юнит, авто, интеграционные). При необходимости локально запускают сервер для теста апи. 5) Если тесты успешно пройдены, то сборка докер образа 6) Отправка образа в registry

    CD - непрерывная доставка или непрерывной развертывание (Continuous Delivery / Continuous Deployment). Так же задается пайплайном и по сути это скачивание образа с registry и развертывание контейнера (Там есть нюансы из разряда, сначала проверяется всего ли хватает у текущего контейнера, поднимается копия, проверяется, перенаправляется трафик и ток потом вырубается 1ый). В случае непрерывной доставки деплой автоматом не происходит - это делает человек, в случае непрерывного развертывания, деплоится само.

  • IaC (Infrastructure as Code)

    • Для удобной раскатки серверов и их настройки используется подход IaC. Принцип заключается в том, что условия развертывания и настройки серверов мы указываем в коде через Terraform (Создание серверов) и Ansible(Настройки). Например в Terraform указываем скок хотим сервером и их ip, а в terraform коде указываем какие программы установим и до какой версии обновим линукс.Эти файлы хранятся с кодом, так что там доступно версионирование и коммиты

  • Мониторинг

    • Grafana + Promethus - Логирования состояния

    ELK / Datadog / OpenSearch + OpenSearch Dashboards - Общая система логов

    Так же настраивается система алертинга. Например мониторинг + алертинга Zabbix

  • Программирование

    • Это необходимо для автоматизации рутинных действий: Изменение скриптов например. Для чтения кода и тестов, какие зависимости нужны и тд, для настройки Docker/Terraform и тд

    Основные языки: Python, Bash, Go. В идеале еще Node js, Java, C#
